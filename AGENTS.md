# frame-space

Small Next.js 16 app (App Router, single package, npm). "Frame space" — authentication is the implemented feature so far (email/password + Google sign-in/sign-up).

## Commands

- Dev server: `npm run dev` (Turbopack is the default bundler in Next 16).
- Lint: `npm run lint` (ESLint 9 flat config; runs `eslint` with no args over the repo).
- Typecheck: `npx tsc --noEmit` — route types live in `.next/types/**` and `.next/dev/types/**`, which are generated by `next dev`/`next build`. If typecheck fails on `PageProps`/`LayoutProps`/route params, run `npm run dev` (or `npm run build`) once first.
- Full verification: lint + typecheck; there is no test framework, so build with `npm run build` for end-to-end validation.

## Next.js 16 config gotchas (next.config.ts)

- `reactCompiler: true` is enabled — do not add manual `useMemo`/`useCallback`/`memo`; follow the Rules of React strictly (Compiler breaks on mutation/impure effects).
- `cacheComponents: true` — data fetching is dynamic by default. Cache explicitly with the `use cache` directive, and any dynamic data on a prerendered route must be inside `<Suspense>`. Do **not** add `runtime` route segment config (unsupported), and don't use the removed `experimental_ppr`/`experimental.ppr` patterns.
- Tailwind v4 is wired through a `turbopack.rules` CSS loader in `next.config.ts` — there is no PostCSS config. Don't "fix" the missing `postcss.config`.

## Auth (Better Auth + MongoDB)

- Server: `src/lib/auth.ts` exports `auth` (better-auth instance with mongodbAdapter; database name is hardcoded to `frame-space`, and a Mongo connection opens at module load — importing it requires a reachable `MONGODB_URI`).
- Client: `src/lib/auth-client.ts` — build new client calls off the exported destructure (`signIn`, `signUp`, `useSession`).
- Auth API is mounted at `src/app/api/auth/[...all]/route.ts` (`/api/auth/*` to the better-auth handler).
- Auth UI pages live in the route group `src/app/(Authentication)/` (`/sign-in`, `/sign-up`); client pages use `router.push` + `react-toastify` `toast()` for feedback.
- Required env vars (`.env` at repo root, gitignored — never commit or echo values): `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `MONGODB_URI`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`.

## Conventions

- Path alias `@/*` → `src/*`.
- Shared components sit in `src/app/Componets/` (sic — folder name is misspelled; keep it for consistency with `Header.tsx`).
- Styling: Tailwind v4 + daisyUI 5 via `@plugin "daisyui"` in `src/app/globals.css`; layout sets `data-theme="light"`. Prefer daisyUI semantic classes (`btn`, `card`, `hero`, `fieldset`).
